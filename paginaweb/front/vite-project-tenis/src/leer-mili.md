Para cualquier codigo que quieras hacer respecto a css, vas a tener que poner:

/file.css

@import "tailwindcss";


Esto va a traer todos los files predeterminados para tailwind.



El .tsx es el archivo sobre el cual vas a poner los estilos traidos desde tailwindcss.

Podes googlear en la documentacion o usar gpt para ver como estructurar el proyecto y definir .tsx y .css correctamente.
